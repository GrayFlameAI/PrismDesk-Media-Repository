# Prismdesk媒体宝库

Local-first  media manager

Prismdesk is a private local asset library for your images and videos.
It parses embedded metadata from media files. All indexing and search run locally on your device. No files are uploaded to cloud.

### Features

- Auto parse media metadata
- Local natural language / visual similarity search
- Watch folders, auto-index new files
- Support images & videos, thumbnail preview
- Filter by tag, rating, date and file type
- Virtual collections, batch operations
- Non-destructive indexing: original files stay in place

## ✨ Prismdesk媒体宝库

本地媒体素材管理工具

### 📌 项目简介

一款纯本地运行的图片、视频素材管理软件。采用原地索引机制，**不会移动、复制、修改你的原始文件**，所有素材信息保存在本地，保护你的素材隐私。

### 🧩 核心功能

- ✅ **媒体元数据自动解析**
自动读取素材内嵌元信息，提取备注、参数等内容，一键查看素材附带信息
- ✅ **多格式媒体支持**
兼容图片、视频文件，自动生成缩略图，支持视频预览
- ✅ **文件夹监听自动入库**
监听指定目录，新增素材自动扫描加入素材库，无需手动导入
- ✅ **高级筛选系统**
支持按标签、评分、时间、文件类型等条件筛选；支持自定义标签、五星评分
- ✅ **虚拟合集（收藏夹）**
自由创建素材合集，仅建立引用关系，不会改动原有文件目录结构
- ✅ **批量操作**
批量标记、导出、复制、打开文件所在目录，快速整理素材
- ✅ **轻量化本地架构**
索引数据全部存放在本地，支持万级素材流畅浏览
