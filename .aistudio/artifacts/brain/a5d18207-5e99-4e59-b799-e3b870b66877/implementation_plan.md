## 1. 核心目标与价值概览 (Overview & Core Concept)

- **核心定位**：打造真正生产级的本地多媒体私密资产保险箱与高性能工作站。
- **解决的核心痛点**：
  1. **消除安全隐患并兼顾易用提示**：移除原先防君子不防小人的“忘记密码一键重置”后门，在锁屏界面提供清晰的「初始密码 123456」小提示，并加入 5 次错误 30 秒防暴破锁定。
  2. **内外文件实时一致**：提供显式的工具栏「刷新」按钮，并结合 Node.js `fs.watch` 监听外部 Windows 资源管理器的文件增删改，做到外部拖入或删除文件后应用自动静默同步。
  3. **根治大体积视频内存溢出 (OOM)**：杜绝在渲染进程使用 `FileReader.readAsArrayBuffer` / `readAsDataURL` 读取大体积视频文件，改为纯物理路径 + 主进程异步分块流式复制，轻松应对 700MB+ 单体视频或 30+ 批量视频导入。

## 2. 用户体验与视觉设计 (User Experience & Visual Design)

### 关键交互流程
1. **高强度锁屏与防暴破体验**：
   - 启动应用即呈现 Windows 11 风格毛玻璃锁屏页（支持白天/黑夜双主题与中英切换）。
   - **锁屏小提示**：在密码输入框下方显示 **`初始密码 123456`** 小提示（替代原有的“忘记密码？”位置），彻底移除任何重置后门。
   - 每次输错密码实时提示剩余尝试次数（例如：`密码不正确，还剩 X 次尝试机会`）；累计满 5 次错误后，输入框自动禁用并显示红色安全倒计时横幅（`连续输错 5 次，已安全锁定 (30s)...`），倒计时结束后自动恢复输入。
2. **文件夹工具栏「刷新」按钮与静默热加载**：
   - 进入任意文件夹视图（或分类根目录）时，右上角工具栏在「排序 / 视图切换」与「新建文件夹 / 导入素材」旁新增 **「刷新」按钮**（带 `RefreshCw` 旋转动效图标）。
   - 点击「刷新」时图标平滑旋转一圈，立即触发物理磁盘重扫并弹出轻量 Toast 提示；当用户在外部 Windows 文件夹直接增删文件时，主进程 `fs.watch` 经 350ms 防抖后自动通知前端静默更新列表。
3. **零内存大文件导入体验**：
   - 在导入弹窗或主窗口直接拖入 700MB+ 大视频或 30+ 素材时，前端仅记录文件的物理路径 `file.path`、文件名与文件大小，对于大体积文件直接展示轻量文件图标卡片而非耗费内存解码，确认后交由主进程队列流式复制并实时反馈进度（如 `正在流式复制 12 / 35...`）。

### 视觉规范与双主题令牌
- **白天模式 (Light Mode)**：纯白背景 (`#FFFFFF` / `bg-slate-50`) + 天蓝主色 (`#0EA5E9` / `bg-sky-500`) + 清透毛玻璃顶栏。

## 3. 核心架构决策与权衡 (Key Product Decisions & Trade-Offs)

- **决策 1：纯路径流式管道复制 vs. 渲染进程内存读取**
  - *采用方案*：前端通过 Electron `file.path`（拖拽或 `<input>`）或 `dialog.showOpenDialog` 获取源文件绝对路径，仅将路径字符串数组通过 IPC 发送至主进程；主进程采用异步并发队列（Chunk Size = 4）结合 `fs.createReadStream` / `fs.createWriteStream` 流式管道与 `fs.promises.copyFile` 完成磁盘同步。
  - *原因*：彻底将渲染进程内存占用降至接近 0 MB，避免 Chromium V8 堆内存上限导致的白屏崩溃。
- **决策 2：带防抖（Debounce）的 `fs.watch` 热加载机制**
  - *采用方案*：在主进程对 `vaultRootPath` 开启递归 `fs.watch({ recursive: true })` 监听，过滤 `.prism_meta.json` 等内部元数据临时写入，并使用 350ms 防抖合并高频磁盘事件后向渲染进程发送 `vault:fsChanged` 事件。
  - *原因*：当外部批量拷入几十个文件时，操作系统会瞬间触发上百次 `fs.watch` 事件；防抖合并可保证界面仅在文件写入稳定后平滑刷新一次，兼顾实时性与零卡顿。

### 核心状态与交互映射
1. **安全配置与防暴破状态 (`SecurityConfig` + Lockout State)**：
   - 若配置文件中尚未初始化密码哈希，自动写入 `123456` 的 SHA-256 哈希值并将 `isPasswordSet` 设为 `true`。
   - `LockScreen` 在密码输入框下方展示 `初始密码 123456` 小提示，彻底移除“忘记密码？”按钮与重置逻辑。
   - `LockScreen` 维护 `failedAttempts`（错误次数）与 `lockoutUntil`（锁定截止时间戳，同步写入 `localStorage` 防刷新绕过）。当 `failedAttempts >= 5` 时设置 `lockoutUntil = Date.now() + 30000`，每秒更新剩余秒数，归零后重置计数。
   - `SettingsModal` 强制要求验证当前旧密码后方可设置新密码，并彻底移除“取消密码保护”入口。
2. **手动刷新与 `fs.watch` 自动热同步**：
   - `BreadcrumbBar` 新增 `onRefresh` 回调与 `isRefreshing` 旋转状态，点击后调用 `reloadData(true)` 并反馈提示。
   - 主进程启动或切换根目录时挂载 `fs.watch`，监听到外部物理文件变更后触发 `mainWindow.webContents.send('vault:fsChanged')`（Web 预览环境通过 SSE / 版本号轮询同步感知），前端收到事件后静默调用 `reloadData(false)` 更新视图而不打断用户当前操作。
3. **零内存大文件流式导入 (`dialog:selectMediaFiles` & `fs:batchImport`)**：
   - 在 Electron 环境下，导入弹窗支持原生文件多选对话框或 `file.path` 获取绝对路径；严禁使用 `FileReader.readAsArrayBuffer` 将大视频读入内存，直接将路径交由主进程分块流式队列复制，并在复制过程中通过 IPC 事件 `fs:importProgress` 实时向前端推送当前完成数与总数。
