# PrismDesk Media Vault - 创意设计与视频素材中心

为视觉设计师、剪辑师打造的 Windows 桌面级统一媒体资源管理系统，提供素材图、成品图、二次放大、舞蹈视频、视频素材、最伟大作品 6 大专属区域，支持自定义封面文件夹、原地平滑悬停微缩放大与即时视频预览、跨目录剪贴板操作，并搭载 Windows 风格安全锁屏。

## 用户审核与关键决策确认

> [!IMPORTANT]
> 基于第一轮的澄清确认，系统已确立以下核心规格：

- **确认决定 1（初始数据）**：系统启动采用纯净空文件夹结构，支持用户自主新建子文件夹、批量导入本地图片/视频文件，并预留可选的“加载示例体验包”按钮供随时试用。
- **确认决定 2（放大交互）**：鼠标指针悬停时采用**原地平滑放大微缩卡片**（不遮挡全局网格，带有微小高亮阴影和卡片内视频流畅静音预览），双击或点击展开全屏高清灯箱。
- **确认决定 3（界面风格与安全）**：采用 Windows 11 Fluent 桌面应用风格（包含顶层标题栏、最小化/最大化/关闭按钮模拟、亚克力玻璃质感、面包屑导航与右上角返回上一级按钮），并配备 Windows Hello 风格锁屏验证与密码管理。

## 1. 系统概述与核心理念

- **解决痛点**：设计师与视频剪辑师日常需要频繁在 Windows 文件资源管理器的繁杂层级中来回跳转找图找视频，效率低且预览不便。
- **目标用户**：平面设计师、电商美工、AI生图创作者、舞蹈剪辑师与视频创作者。
- **核心价值**：
  - 聚焦 6 大工作流专用区（素材图、成品图、二次放大图片、舞蹈视频素材、视频素材、最伟大的作品）。
  - 直观的卡片悬停无感放大与视频动态预览，无需频繁打开播放器。
  - 文件夹支持快速上传或选取自定义展示封面图，分类赏心悦目。
  - 完整的复制、粘贴、移动、删除与批量选择管理，结合浏览器持久化存储（IndexedDB），刷新不丢文件。

## 2. 界面视觉与交互体验设计

### 核心操作流程
1. **密码保护与欢迎解锁**：初次启动可自由设置访问密码；后续打开软件显示 Windows 风格磨砂毛玻璃锁屏界面，输入密码即可进入；顶部常驻一键快速锁定与修改密码弹窗。
2. **六大分类工作区切换**：左侧/顶部快速进入 6 大专属专区（素材图、成品图、二次放大图、舞蹈视频、视频素材、最伟大的作品）。
3. **文件夹自定封面与进入**：每个区域可创建多个分类文件夹，每个文件夹卡片均支持快捷设置自定义封面图与查看文件数量。
4. **层级穿透与快速返回**：进入文件夹后，右上角常驻高亮“返回上一级”按钮与当前路径面包屑，支持一键回退与层级跳转。
5. **原地平滑卡片缩放**：
   - 鼠标悬停在图片卡片上，微缩卡片以 `scale-110` 平滑原地放大展开，展现高对比度细节与尺寸参数。
   - 鼠标悬停在视频卡片上，视频在卡片内自动静音循环播放，并附带视频时长与编码角标。
6. **剪贴板操作与媒体管理**：
   - 支持选中单张或多选文件后点击“复制”，切换到其他文件夹执行“粘贴”（复制副本）或“移动”。
   - 支持批量与单项安全删除，附带操作撤回提示与删除确认。

### 视觉语言（Windows 11 Fluent / Acrylic 现代深浅桌面质感）
- **色彩规范**：
  - 60% 主画布：深色模式为碳黑到岩板灰（`#0B0F17` / `#111827`），浅色模式为纯净亚克力白（`#F8FAFC`）。
  - 30% 结构层：精细 1px 微发光边框（`rgba(255, 255, 255, 0.08)`），卡片磨砂质感。
  - 10% 强调色：Windows 蓝（`#0078D4` / `#2563EB`）与高亮紫晶点缀，用于主要操作与选中状态。
- **排版结构**：
  - 系统字体：`Plus Jakarta Sans` 搭配无衬线界面字体，数字采用 `tabular-nums` 等宽对齐。
  - 元数据展示：零胶囊药丸设计，使用纯净微文本与中圆点隔开（例如：`3840×2160 · 4.2 MB · MP4`）。

## 3. 关键架构决策与技术权衡

- **决策 1：文件数据本地持久化存储**
  - *方案*：采用浏览器原生 `IndexedDB` 驱动的大容量二进制存储机制，配合内存对象 URL（`URL.createObjectURL`）。
  - *原因*：用户导入的超清设计图与高码率视频文件体积极大，`localStorage` 仅有 5MB 限制会迅速崩溃；`IndexedDB` 可容纳数 GB 的本地媒体，保证关掉网页或刷新后媒体库完整保留。
- **决策 2：原地悬停放大与视频播放性能优化**
  - *方案*：卡片采用 CSS 硬件加速变换（`will-change: transform`，仅过渡 `transform` 与 `box-shadow`），卡片悬停加入防抖（debounce 120ms）触发视频播放，离开时立即暂停并复位，避免多视频同时解码卡顿。
- **决策 3：虚拟剪贴板（Clipboard Engine）**
  - *方案*：在前端状态机中建立应用级剪贴板，支持 `COPY` 与 `CUT` 模式。用户在任何文件夹内执行复制后，目标文件夹右上角工具栏与右键菜单均高亮提示“粘贴 (N个文件)”，实现无缝文件搬迁。

### 实体数据模型
- **CategorySection**: 固定的 6 大核心专区 ID (`materials`, `finished`, `upscaled`, `dance_videos`, `video_assets`, `masterpieces`)。
- **Folder**: `{ id, sectionId, name, coverUrl, createdAt, description }`
- **MediaItem**: `{ id, folderId, sectionId, name, type: 'image' | 'video', blobOrUrl, size, dimensions, duration, createdAt }`
- **SecurityConfig**: `{ isPasswordSet, passwordHash, isLocked, hint }`
- **ClipboardState**: `{ action: 'copy' | 'cut', items: MediaItem[] }`
